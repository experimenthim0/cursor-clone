# Cursor Website Clone

This is a frontend clone of the Cursor website, built using HTML and CSS.
I created this project to practice modern landing page design, layout structuring, and clean UI implementation.

🔗 Live Demo: [https://cursor-clone-sepia.vercel.app/
](https://cursor-clone-sepia.vercel.app/)

## ✨ What I Built

I recreated most of the main sections from the original Cursor website, focusing on layout, spacing, and visual flow.

### Sections Included

1. **Navigation Bar**

  -   Logo, menu links, sign-in and download buttons

2. **Hero Section**

- Main headline

- Download for Windows button

3. **Product Preview Section**

- Large hero image similar to the original site

4. **Trusted By Section**

- Text and company logos showing trust by developers

5. **Features Section**

- Agent turns ideas into code

- Accurate autocomplete

- Cursor ecosystem

- Alternating text and image layout

6. **Testimonials**

- User feedback cards with profile image and role

7. **Feature Cards** (Stay on the frontier)

- Model access

- Codebase understanding

- Enterprise-level development

8. **Changelog Section**

- Recent updates with versions and dates

9. **Join Us / Team Section**

 - Call-to-action with team image

10. **Final CTA**

- Download prompt

11. **Footer**

- Product, resources, company, legal, and social links

### 🎨 Fonts & Styling

- Uses CursorGothic and sans-serif fonts for a clean and modern look


🎨 Color Palette

- The design follows a minimal and professional color scheme inspired by Cursor:

Black – Primary text

White – Text

Gray shades – Secondary text and borders ,background

Orange – Highlights, links, and accent text

### 🛠 Tech Stack

- HTML5

- CSS3
